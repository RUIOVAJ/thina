Thina(θινα) 编程语言使用手册 🎋

~~书写 Thina 代码就像建造自己的小岛一样——从清理杂草（去除随机数）到选址建造（写程序），再到搭建工坊（函数）。

Thina（简称 Tn）是一门极简编程语言，核心只有六件事：值与地址、运算、循环、条件、函数、输入输出。

⚡ 在线试玩（即时运行）

写 Thina 或 bento（以 🍱 开头）代码，点「编译 ✓」查语法、「运行 ▶」执行；「输入」栏：Thina 填十六进制、bento 填食物 emoji（可空）。

一、存储模型 🏝️

    
    
      
  • 半字节空间：地址从 0 开始连续编号，每个地址存一个半字节（0–15），无限延伸。
    • 
      
  • 函数仓库：按数字标号寻址，每个标号存一个函数。初始时每个标号都是空函数（调用它什么都不做）。
    • 
      
  • 初始随机：半字节空间的每个格子初始值都是随机的，且不可复现（每次运行都不同）；函数仓库初始是空函数，不参与随机。
    • 
      
  • 零耦合：函数标号与字节地址编号互不干扰——标号 a 的函数 ≠ 地址 a 的半字节。
    • 
    

  

  

    
二、数字与字面量 🕯️

    
    
      
  • 十六进制：所有数字以十六进制书写，字母大写（0–9、A–F）。
    • 
      
  • 低位在左：最左字符是 16⁰ 位，往右指数递增。此规则贯彻到半字节内部的 nibble：
        
      
          
    • AB = A + 16·B
      • 
          
    • <0000> 是 4 半字节的 0；<00> 是 2 半字节的 0。值相同，宽度不同。
      • 
        
    
      
    • 
      
  • 三种写法：裸写、<...>（字面量）、[...] / (...)（取值）。
    • 
    

    
词法与空白规则

    
    
      
  • 数字可不加 <> 直接裸写；连续十六进制字符是一个数：23 是值 35 的一个数，不是两个数。
    • 
      
  • 运算符 = + - # 不是十六进制字符，能自动切开数字，两侧无需空格：2=3、2+3 合法。
    • 
      
  • 两个裸数字相邻时，必须用空格 / 回车 / 制表符之一分隔。
    • 
      
  • 带 : 或 | 修饰的数字必须加 <> 或 []：裸写 2|2、2:1 非法。
    • 
      
  • 需要「两个数字紧挨」的语法（?、^ 及 & 条件比较）不能用裸数字，必须用 <> / [] 包住：^ 1 2 非法，^<1><2> 合法。
    • 
    

    
10(Thina) = 1 + 0·16 = 1(十进制)   * Thina 中 10 表示现实数字 1 *

  

  

    
三、取值与地址表达式 📍

    
    
      
  • () 与 [] 完全等价，可任意层级互换，仅用于便于观察。注意：两种括号等价，但需相互匹配（(] 或 [) 不允许）。
    • 
      
  • [A]：地址 A 处 1 半字节的值。
    • 
      
  • [A|n]：从 A 起 n 个半字节组成的大数整体（A 为最低位）。
    • 
      
  • [A:n]：地址 A+n 处的值。
    • 
      
  • [A:n|m]：先 : 后 |，即从 A+n 起取 m 半字节整体。
    • 
      
  • 可嵌套，例如 [(3):(A)|(B)]。
    • 
    

    
字面量的宽度强制 |n

    
    
      
  • 把字面量重解析成固定 n 个半字节：比 n 短则高位补零，比 n 长则保留低位 n 位。
        
      
          
    • <2|2> → 20（值 2，宽 2）
      • 
          
    • <1234|2> → 12（值 33，宽 2）
      • 
        
    
      
    • 
      
  • 偏移 :n：把数向高位方向移 n 格（低位补 n 个零）。<1:2> → 001。
    • 
    

    
<0>=<ABCD> #[0|4]

    
ABCD

  

  

    
四、运算 ➕

    
三个运算符，目标都是格子（地址）：

    

      
写法含义

      
a+b把 b 加到地址 a 的格子上（就地加）

      
a-b把 b 从地址 a 的格子上减去（就地减）

      
a=b把 b 写到地址 a 起

    

    
    
      
  • 加、减（+ / -）：纯数值运算，忽略操作数宽度。进位、借位向地址增大方向无限传播，无上限。
        
      
          
    • 0+1 与 0+10 等价（都加值 1）。
      • 
          
    • [0]=F 时 0+1 得 [0]=0、[1] 自增 1。
      • 
        
    
      
    • 
      
  • 赋值（=）：按 b 的书写宽度逐半字节落盘。若 b 超过 1 半字节，多余部分向地址增大方向继续写。
        
      
          
    • <0>=<ABCD> → [0]=A，[1]=B，[2]=C，[3]=D。
      • 
        
    
      
    • 
    

    
0=F 1=0 0+1 #[0|2]

    
01

    
0=0 1=1 0-1 #[0|2]

    
F0

  

  

    
五、循环 🔄

    
    
      
  • %{ ... }：反复执行花括号内内容。
    • 
      
  • ? a b：比较 a、b 的数值（忽略宽度），相等则跳出一层循环。
    • 
      
  • ^ a b：与 ? 相反，若 a、b 相等，继续循环，不相等跳出。
    • 
      
  • 单独 ? 或 ^：无条件跳出当前（最内层）循环。
    • 
      
  • ' 表示大于小于，与 ^、? 搭配：?' 左边小于右边跳出循环；^' 左边小于右边继续循环。
    • 
      
  • ?、^ 的两个操作数必须用 <> 或 [] 包住（不能用裸数字）。
    • 
    

    
0=0 %{ 0+1 ?<5>[0] } #[0]

    
5

    
0=0 %{ 0+1 ^[0]'<5> #[0] }

    
1234

  

  

    
六、判断 🌿

    
&<1><1>{...}<1>'<2>{...}{...} 表示条件链：条件一成立执行后面大括号中语句，不成立进行下一个，以此类推。也可以不加条件，作用类似 else。条件中的两个操作数同样须用 <> / [] 包住。

    
0=0 &<1><1>{ 0=1 }<1><2>{ 0=2 }{ 0=3 } #[0]

    
1

  

  

    
七、输入输出 💾

    
输入

    
    
      
  • $ 表示输入值，可当数字用。
    • 
      
  • $：一次读 1 个半字节（1 个十六进制字符）；也可写成 <$>。
    • 
      
  • $|n：一次读 n 个半字节组成整体，先读的是最低位（最左端）。
    • 
      
  • $:n：先跳过 n 个半字节再读（读 1 个）。
    • 
      
  • $:n|m：跳过 n 个半字节，再读 m 个成整体。
    • 
      
  • 输入只读十六进制字符（0–9、A–F），其余忽略；读到输入末尾（EOF）视为读到 0。
    • 
      
  • $ 可出现在 [] 和 () 里当地址，如 [$]。
    • 
    

    
输出

    
    
      
  • # a：输出 a 的数值。
    • 
      
  • 格式：十六进制、大写、低位在左，按值的固有宽度打印。固有宽度 = 半字节个数，前导零保留：#00 输出 00，#<0|2> 输出 00。
    • 
      
  • 不换行、不加分隔符，输出流完全由程序控制。
    • 
    

    
0=$|2 #[0|2]   * 输入 12 *

    
12

  

  

    
八、函数 🏭

    
    
      
  • { ... }~ a：把花括号内的操作存到函数仓库标号 a（覆盖写）。
    • 
      
  • {}~a：把标号 a 覆盖回空函数。
    • 
      
  • a!：运行标号 a 的函数；a 是数字表达式。
    • 
      
  • 函数体看到全局字节空间，无局部帧。
    • 
      
  • 函数体执行到 } 自动结束；/ 提前结束，功能等同 return，无返回值。
    • 
      
  • 支持嵌套与递归调用。
    • 
    

    
{ 0+1 }~<5>   * 定义函数：地址 0 加 1，命名为函数 5 *
5!            * 调用 *

    
0=0 { &<5>[0]{ / } 0+1 5! }~<5> 5! #[0]   * 递归：加到 5 停 *

    
5

  

  

    
九、注释 ✏️

    
用 *内容* 进行注释，可以跨行。

  

  

    
十、设计原则 🧭

    
    
      
  1. 地址模型贯穿一切：变量是地址、传参传地址、返回值靠写地址、I/O 读写地址里的值。
    2. 
      
  2. 低位在左，全局统一：书写、半字节内 nibble、多字节整体，一律左边是最低位。
    3. 
      
  3. 宽度是一等属性：值的半字节数参与语义，前导零不消除。
    4. 
      
  4. 两套存储、零耦合：半字节空间与函数仓库互不干扰。
    5. 
      
  5. 语法极小：() [] 等价、: 先于 |、/ 即 return。
    6.

A.3 书写差异

    
    
      
  1. 修饰符总在右（后缀记法）：数字 → 修饰符链 → 下一个记号。
        
      
          
    • <AB> → 🍗🍖🍊
      • 
          
    • [0] → 🍢🍐
      • 
          
    • [1|2] → 🍟🍕🧆🍐
      • 
          
    • [0:1] → 🍢🍔🍟🍐
      • 
          
    • <$|n> → 🍨🍕n🍊
      • 
        
    
      
    2. 
      
  2. 循环定界靠深度交替：第 1 层 🥨，第 2 层 🥖，第 3 层 🥨……配对由深度唯一确定。
    3. 
      
  3. 条件链（&）靠数字反写实现：比较操作数把定界符写在数字前面（与正常后缀相反），执行体用 🧂🧂 括起。反写只移动定界符位置，数字自身顺序（低位在左）与 :/| 顺序不变。例：
        
    🍊🍢🍐🍢🧂...🧂🍊🍢🍊🍢🧂...🧂
    
        即 <0 [0 {…} <0 <0 {…}，对应 Thina 的 &<0>[0]{…}<0><0>{…}。
      
    4. 
    

    
A.4 bento 专属词法规则

    
    
      
  • 不支持省略：每个字面量必须以 🍊 收尾、每个取值必须以 🍐 收尾，无裸数字。
    • 
      
  • 无注释语法，但：所有非关键字 emoji 一律忽略（可出现在任意位置，含数字中间）；所有非 emoji 字符（字母、标点、空白等）直接当注释，忽略。
    • 
      
  • 🍱 是关键字（保留字），仅在源码开头起切换模式的作用。
    • 
    

    
A.5 转换关系

    
    
      
  • bento → Thina：词法替换 + 后缀转前缀 + 循环深度栈还原 + 条件反写还原。
    • 
      
  • Thina → bento：词法替换 + 前缀转后缀 + 按深度选 🥨 / 🥖 + 条件反写。
    • 
    

    
转换器本质是一个带定界符状态的后缀记法重写器，无信息丢失。顺带一提：bento 的输入与输出都是食物 emoji（输入也按 🍢🍟🧆… 映射为半字节）。
